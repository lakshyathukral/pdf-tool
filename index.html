Photos

Each picture becomes a page. Turned the right way up using the camera's own orientation, and shrunk to a sensible size so a dozen photographs do not make a file nobody can email.

On a phone, "Add photos" offers the camera directly.

Make the file smaller

Every page is turned into a picture at a lower resolution. The file gets much smaller and still looks right on screen. The trade is that the text stops being selectable or searchable.

Save as pictures

Each page becomes its own image file. More than one page comes back as a single .zip.

            Watermark

            Hindi letters show when the words are in Hindi.

            Repeating makes it harder to remove cleanly — a PDF editor has to delete nine separate pieces of text instead of one, and a partial job shows. To stop it being editable at all, use "Flatten pages" under Saving.

            To leave the watermark off one page, open that page full size and tap it.

            Presets

            Save the numbering, watermark and text settings under a name and reuse them. Kept in this browser only.

            Password

            Add a PDF. If it is protected you will be asked for its password.

            To remove a password: open the file — you will be asked for it — then save with this box unticked. To add one: tick the box, choose a password, save.

            Removing a password needs the password. This cannot unlock a file you do not have the password for.
